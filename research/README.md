# Research

What we gathered that is not yet worked into a deliverable: vendor
documentation, competitor captures, a spike, a pricing page.

One subfolder per topic, never per person. Git already records who added what,
so a folder named after someone buys nothing and costs findability.

Each subfolder carries a `README.md` with front-matter. A filename tells an
agent nothing; the README is what makes the material findable.

When something fits nowhere else, it goes here and you name the topic. Being
made to name it is the point.
