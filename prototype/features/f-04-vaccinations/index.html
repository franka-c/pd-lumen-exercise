Interaction rules

  • "Dospijeva": everything VetDesk returns, sorted by date, so overdue comes first. Calm and neutral, no red, no warning (D-033). No "soon" window is calculated (D-014).
  • "Rezerviraj" opens F-05 with the pet, type Cijepljenje and the item's clinic: ../f-05-booking/index.html?state=book&pet=<id>&type=vaccination&clinic=<id>.
  • If the pet already has a requested or confirmed vaccination appointment in the future, each due item shows "Termin rezerviran: …" instead of the button.
  • Nothing due: "Nema dospjelih cijepljenja." No history: "Još nema cijepljenja u kartonu."
  • Deceased pet: history only (D-031). VetDesk not answering: last saved data with a notice, as F-02.
