Interaction rules

  • Defaults: one pet is preselected; with several, none is. Clinic and vet default to the pet's usual ones (D-002).
  • Change pet: clinic and vet reset to that pet's usual ones; type, day, time cleared.
  • Change clinic: vet, type, day, time cleared. Change vet: time cleared. Change type: time cleared.
  • Send is disabled until pet, clinic, vet, type, day and time are all set. While sending it shows "Šaljem…" and cannot be pressed again.
  • Success: back to Termini, new card on top as Requested, toast "Zahtjev je poslan".
  • Time taken (VetDesk rejects the write): the time is cleared, times reload, everything else kept.
  • Send failed: error above the button, choices kept, button reads "Pokušaj ponovno".
  • Emergency: call notice with the clinic's phone above Send. The request can still be sent.
  • Vaccination with nothing due: warning with next due date. The request can still be sent.
  • Cancel request: confirmation sheet, not undoable. Card disappears, toast "Zahtjev je otkazan".
  • "Odaberi drugi termin": booking opens with the same pet and clinic (D-020) and the same vet and type (proposal 2).
  • Close after a time is chosen: "Odbaciti rezervaciju?" Before that, it just closes.
  • Push: on confirmation (designer decision) and on rejection (D-020). Tapping it opens Termini.
