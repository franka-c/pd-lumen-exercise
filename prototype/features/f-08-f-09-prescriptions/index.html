Interaction rules

  • "Zatraži obnovu" is enabled from 7 days before next_eligible (UNCONFIRMED, Q-021); before that it is disabled with "Obnovu možete zatražiti od …".
  • One open request per prescription: while requested, the card shows the status and "Povuci zahtjev" (asks first) instead of the button.
  • The request shows exactly what the vet sees (D-004): pet, medicine, dose, last consultation, last dispensed; then the optional note with a live character count.
  • Approved: "Preuzimanje od … u klinici …", push. Declined: reason and the vet's text, push, "Zatraži ponovno" if the window is open.
  • Home card (F-09): from 7 days before next_eligible until a request is sent; an approved prescription stays on Home until the pickup day has passed.
  • A pet that has died has no prescriptions (D-031).
